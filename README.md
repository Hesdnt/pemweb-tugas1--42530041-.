# Portofolio Pengembang Web (Tugas 1 Pemrograman Web)

Landing page responsif Tema C, dibuat tanpa framework CSS.

## Fitur
- HTML5 semantik: header, nav, main, section, article, aside, footer
- Hierarki heading runtut (h1 > h2 > h3) dan alt deskriptif pada semua gambar
- Flexbox untuk navigasi, grup tombol, dan daftar tag; CSS Grid untuk layout dan galeri kartu
- Mobile-first dengan breakpoint min-width 768px dan 1024px
- Tanpa JavaScript, tanpa horizontal overflow

## Struktur
```
index.html
css/style.css
assets/images/   (SVG)
assets/icons/    (SVG)
```
