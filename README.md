# 🎨 Graphic Designer Portfolio

Website portofolio sederhana untuk menampilkan profil, karya desain, keahlian, pengalaman, dan kontak seorang **Graphic Designer**.

## 📌 Tentang Project

Project ini dibuat sebagai **Tugas 1 Pemrograman Web** dengan menggunakan HTML dan CSS. Website dirancang untuk menjadi media portofolio yang menampilkan berbagai hasil desain serta informasi mengenai kemampuan dan pengalaman sebagai graphic designer.

## ✨ Fitur

* Hero section dengan perkenalan singkat
* About Me
* Project / karya desain
* Skills dan software yang dikuasai
* Pengalaman
* Kontak dan jejaring sosial
* Responsive layout
* Navigasi antar-section
* Skip link untuk meningkatkan aksesibilitas
* Optimasi gambar menggunakan `loading="lazy"`

## 🛠️ Teknologi yang Digunakan

* HTML5
* CSS3
* SVG
* Git & GitHub
